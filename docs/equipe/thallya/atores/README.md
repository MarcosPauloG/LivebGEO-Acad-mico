# Atores do sistema

| Ator | Descricao e objetivo | Capacidades principais |
|---|---|---|
| Coordenacao academica | Perfil ficticio responsavel por demonstrar e revisar integralmente o prototipo. | Consulta todos os modulos, planeja visitas, compara rotas e consulta acessos. |
| Analise territorial | Perfil ficticio que interpreta a amostra e apoia decisoes didaticas de cobertura e expansao. | Consulta analises, planejamento, rotas e indicadores. |
| Representacao de campo | Perfil ficticio que executa o planejamento de visitas na demonstracao. | Consulta mapa, pontos, visitas, rotas e cobertura; planeja e conclui visitas. |
| Observacao | Perfil ficticio voltado a acompanhamento sem alteracao operacional. | Consulta dados permitidos; nao planeja visitas nem compara rotas. |
| Gestao mock local | Sistema externo simulado por contrato TypeScript; nao e uma integracao real. | Autentica perfis ficticios e devolve permissoes locais. |
