# Atores

> _Abaixo estão descritos os atores e suas respectivas funções dentro do sistema._

**Coordenador Acadêmico:** Consulta todas as visões e demonstra a matriz de permissões.

**Analista Territorial:** Analisa mapa, cobertura, rotas e indicadores, sem administrar acessos.

**Representante de Campo:** Consulta áreas, pontos e registra visitas.

**Observador:** Acompanha as informações predominantemente em modo de leitura.

**Gestão:** Ator externo.

**IBGE:** Ator externo.

**GPS:** Ator externo.
