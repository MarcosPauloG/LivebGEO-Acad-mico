# Filipe — Protótipo e validação

Responsável pela construção do protótipo navegável, definição do fluxo de telas, preparação do roteiro de teste, validação com usuários e registro das correções.

## Situação em 01/10/2026

- Protótipo navegável V1: concluído no Figma;
- Fluxo principal: configurado e conferido;
- Tela inicial: `1-Acesso`;
- Entrevista acadêmica: pendente;
- Validação com usuários: pendente;
- Correções após validação: pendentes;
- Versão final: pendente.

O protótipo atual é uma versão preliminar. Ele não deve ser apresentado como validado enquanto a entrevista e o teste com usuários não forem realizados.
