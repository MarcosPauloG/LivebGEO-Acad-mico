# Protótipo navegável — Liveb GEO

**Responsável:** Filipe  
**Versão:** V1 preliminar  
**Data do registro:** 01/10/2026  
**Status:** concluído visualmente e pendente de validação após a entrevista acadêmica.

## Acesso

[Open prototype in Figma](https://www.figma.com/design/8qv4GgXSTYg1VFw2lJBnhi/Novo-Projeto-Liveb?node-id=0-1&p=f&t=vFSt6jdMJ0aEML1y-0)

## Telas existentes

1. Acesso;
2. Mapa e municípios;
3. Territórios;
4. Representantes e cobertura;
5. Planejamento de visitas;
6. Geração e comparação de rotas;
7. Indicadores de expansão.

## Características verificadas

- Interface identificada como ambiente acadêmico;
- Uso de dados fictícios e sintéticos;
- Ausência de dados reais de clientes, representantes ou operações;
- Fluxo iniciado na tela `1-Acesso`;
- Navegação sequencial configurada entre as sete telas;
- Escopo concentrado no Liveb GEO.

## Limitação atual

Esta versão foi elaborada antes da conclusão da entrevista acadêmica. Portanto, ainda não constitui versão final validada. As conclusões da entrevista e do teste de uso poderão gerar uma V2.
