# Fluxo de navegação

## Fluxo principal verificado

1. `1-Acesso` → `2-Mapa`;
2. `2-Mapa` → `3-Territórios`;
3. `3-Territórios` → `4-Cobertura`;
4. `4-Cobertura` → `5-Visitas`;
5. `5-Visitas` → `6-Rotas`;
6. `6-Rotas` → `7-Indicadores`.

A tela `1-Acesso` está definida como ponto inicial do fluxo **Fluxo principal — Liveb GEO**.

## Objetivo do percurso

O percurso demonstra o acesso acadêmico, a análise territorial, a consulta de cobertura, o planejamento de visitas, a comparação de rotas e a visualização dos indicadores de expansão.

## Observação

A sequência foi conferida tecnicamente no Figma em 01/10/2026. A facilidade de uso ainda deverá ser avaliada por usuários durante a validação.
